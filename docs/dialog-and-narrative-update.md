# ダイアログ・文書登録の変更（2026-11-14）

## 画面

- 共通ダイアログは本文だけをスクロールし、操作フッターに区切り線を表示する。新しい `DialogSectionNavigation` はタイトル下の固定領域から本文内のセクションへ移動する。キャラ、ストーリー、プロット、掛け合いに適用した。
- 一覧の標準セルは長文を三点リーダーにし、既存のセルtitleで全文を確認できる。
- 階級・経歴・舞台・年表の追加と表示切替を同じボタングループに配置する。経歴のラベルは「年表カード」、舞台は「舞台ツリー」、年表は「年表図」。経歴のキャラ設定画面への移動ボタンを削除した。
- 参照モードの選択欄はdisabledのselectではなくreadonlyの入力として表示する。共通チェック・ラジオ・トグルも非活性表示にせず、readonly時の操作を抑止する。編集可否を理由とした作品内画面のdisabled指定をreadonlyに揃えた。未選択時の操作ボタンなど、操作成立条件によるdisabledは維持する。
- 能力・技ダイアログを「基本」「条件」に分ける。技の関連能力・能力詳細は横並び。能力詳細は `PowerSetting` の同じダイアログをreadonlyで開く。
- 相関図の感情・関係の選択欄をズームボタン右へ移し、アイコンと同じ50pxの高さにする。

## ストーリー・プロット・掛け合い

各画面の初期化・編集処理はそれぞれの `.vue` 内に置く。フォルダから一覧へ変更し、新規・編集のどちらも基本情報と明細を同じ登録ダイアログで入力する。入力はコンポーネントrefの公開メソッドを使用する。明細の追加・移動・削除、テンプレート適用はローカルだけに反映する。ストーリー取込も `ImportStory.php` の `Preview: true` で旧解析処理を実行し、書き込み前の行配列として返す。

保存時は既存 `SaveStory.php` / `SavePlot.php` / `SaveExchange.php` に `Mode: 'bundle'` を送る。`Rows` は保存後の全行、`RowsSnapshot` は読込時点の全行ID・更新日時（削除した行を含む）。固定3区分の親・明細処理を `Common/NarrativeBundle.php` で共有し、親・明細・作品更新日時・履歴を同じトランザクションで更新する。旧個別行APIのモードも残す。

旧行保存と同じアドバイザリロックを先に取得し、親と全行をロックする。親の版と明細のスナップショットが異なる場合は409で中断する。既存行のIDを維持し、並び替えは負のindexNumを経由して一意制約を守る。本文のセリフ／独白整形は旧APIと同じ。プロットは起承転結ごとに順序を付ける。

## 作品一覧からの出力

出力形式の下に「出力帳票」を追加し、作品資料・ストーリー・プロットを選ぶ。作品資料は従来の項目チェックボックス、ストーリー・プロットは一覧選択ボタン付きプルダウンを表示する。`GetNarrativeExportOptions.php` と出力APIでは明示的なWorkIdに対して参加・ロック・管理者権限を確認する。現在の選択作品セッションを書き換えない。

## DDL・検証範囲

ストーリー・プロットの概要列追加は指示訂正により撤回済み。今回のDDLは概要列ではなく、StoryRows.actionLine・ExchangeRows.actionLine・SerifInfo.monologue の3つの真偽値列だけを指定のcreate.sql末尾へ追記する。初期値はいずれもFALSE。DBには未適用で、利用前に追記分のALTER文の適用が必要。

フロントの構造・API整合・Vueカスタムレンダラーテスト、旧年表・WBS・相関図の計算比較、PHP構文チェック、本番ビルドを実施する。追加した `Back/tests/narrative-bundle.php` はPDO代替実装で親子一括保存・ID保持・版競合・途中失敗のロールバック・旧本文整形を検証する。実ブラウザでの目視・実DBへの保存・帳票ファイルの閲覧確認は含まない。

## 2026-11-15 行入力・可変列幅の修正

- 行を追加すると子ダイアログを開き、反映した行を旧StoryItem／ExchangeItemのカード一覧に表示する。キャンセルでは一覧を変更しない。上へ・下へボタンは廃止し、旧実装どおり番号指定とドラッグ（タッチを含む）で順序を変更する。プロットは起承転結内で番号を付け、区分をまたぐドラッグを拒否する。すべて親の保存前はローカルだけを更新する。
- セクションナビは親の基本・行一覧の2つだけとする。カードにFormSectionTitleを付けず、子ダイアログを親のスクロール対象へ入れない。
- ストーリーの発言者自由入力はトグルとして語り手の上に置く。独白は本文の上。掛け合いの独白と自由入力トグルは本文直上の同じ行に置く。
- 動詞入力（保存上はActionLine＝動作描写行）が有効な行では、並び順と本文以外のフォームを隠す。切り戻し用のトグルは表示を維持する。保存時には話者・独白・セリフマスタ・心境を消去し、本文は括弧で加工しない。取得・コピー・一括保存・旧行保存API・Word/HTML帳票へ反映する。
- セリフ設定はMonologueチェックを追加する。原文と区分を保存し、カードや帳票では既存の掛け合いと同じ全角括弧の独白表示を使う。マスタ選択の独白区分はマスタを優先する。
- 通常の入力・補助ボタンは44px、相関図の選択欄だけ50px。セル本文の固定200px上限を撤去し、ヘッダーと本文へ同じリサイズ幅を適用する。モバイルのカード表示にはデスクトップの列幅を持ち込まない。経歴はキャラ／年月日と年齢／内容の3段、画像検索の下に20pxの余白を置く。

テストには行ダイアログの反映・取消、ドラッグ・番号指定、親保存前の未送信、既存行ID・版の保持、独白区分、動作描写の非表示項目の消去、帳票の空欄表現、見出しと本文のリサイズ幅を追加した。実ブラウザでのピクセル単位の確認・実DBへのDDL適用・帳票ファイルの実閲覧は未実施。
